# Проверка работы приложения

## Проверка функциональности

Приложение проверял вручную после запуска Next.js и подключения PostgreSQL.

1. Открыл страницу `/companies` и проверил загрузку списка компаний из базы данных.
2. Проверил поиск по названию компании — после ввода текста список корректно фильтровался.
3. Проверил фильтр по городу — отображались только компании выбранного города.
4. Проверил пагинацию — переход между страницами загружал разные наборы компаний.
5. Во время разработки возникла проблема с подключением PostgreSQL через `pg`, после исправления импорта подключения и настройки базы приложение стало корректно получать данные.
