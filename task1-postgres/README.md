# Импорт компаний в PostgreSQL

## Описание

Проект предназначен для загрузки данных о компаниях из JSON-файлов в PostgreSQL.

Загрузчик:

* читает все файлы `page_*.json` из директории с данными;
* загружает данные в PostgreSQL;
* использует `id` из исходного API как уникальный идентификатор компании;
* предотвращает дублирование записей через `ON CONFLICT (id)`;
* создаёт необходимые индексы;
* содержит аналитические SQL-запросы.

```bash
pip install -r requirements.txt
```

---

### 2. Создание базы данных PostgreSQL

Создайте базу данных:

```sql
CREATE DATABASE companies;
```

---

### 3. Настройка переменных окружения

Скопируйте файл:

```
.env.example
```

в:

```
.env
```

Укажите данные подключения к PostgreSQL:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=companies
DB_USER=postgres
DB_PASSWORD=postgres
```

## Структура базы данных

В проекте используется одна таблица PostgreSQL:

```
companies
```

Таблица содержит следующие поля:

* `id` — уникальный идентификатор компании из исходного API;
* `name` — название компании;
* `category` — категория компании;
* `city` — город;
* `address` — адрес;
* `rating` — рейтинг компании;
* `reviews_count` — количество отзывов;
* `site` — сайт компании;
* `phone` — телефон компании.

Поле `id` используется как `PRIMARY KEY`.

Дедупликация реализована через:

```sql
ON CONFLICT (id) DO UPDATE
```

Если компания с таким `id` уже существует в базе, её данные обновляются вместо создания новой записи.

## Запуск

Для запуска импорта выполните:

```bash
python load.py
```

Скрипт выполняет следующие действия:

1. подключается к PostgreSQL;
2. применяет структуру базы данных из `schema.sql`;
3. читает все JSON-файлы из директории `data_pack`;
4. загружает данные компаний в PostgreSQL.

---

## Проверка импорта

Подключитесь к базе данных PostgreSQL:

```bash
psql -U postgres -d companies
```

Проверить количество загруженных записей:

```sql
SELECT COUNT(*) FROM companies;
```

Запустить аналитические запросы:

```sql
\i queries.sql
```

---

## SQL-запросы

Файл `queries.sql` содержит три аналитических запроса:

1. Топ-5 категорий по количеству компаний.
2. Средний рейтинг по городам среди компаний с 10+ отзывами.
3. Доля компаний с сайтом по категориям.

---

## Примечание

В исходном наборе данных присутствуют повторяющиеся записи компаний.

Дедупликация выполняется по уникальному идентификатору компании (`id`), который предоставляется исходным API.
